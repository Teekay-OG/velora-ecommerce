# Velora E-Commerce

A full-stack MERN e-commerce application built with MongoDB, Express.js, React, and Node.js.

## Features

* User Authentication (JWT)
* Admin Dashboard
* Product Management
* Stock Management
* Shopping Cart
* Wishlist
* Order Management
* Cloudinary Image Uploads
* Responsive Design

## Tech Stack

### Frontend

* React
* React Router
* Context API
* React Toastify
* CSS

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* JWT Authentication
* Mongoose

### Services

* Cloudinary
* MongoDB Atlas

## Installation

### Backend

```bash
cd Backend
npm install
npm start
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in the Backend folder:

```env
MONGO_URI=your_mongodb_uri
SECRET=your_jwt_secret
```
